# SureForgeTech

### Tools for software builders.

SureForgeTech builds practical software for the people who make, ship, secure, and operate software. The **SureForge** product family spans developer utilities, coding-agent tools, compliance automation, planning tools, and application platforms—from native macOS apps and command-line tools to editor extensions, Jira apps, and deployable server software.

**[Visit sureforgetech.com](https://sureforgetech.com) · [Explore SureForge.ai](https://sureforge.ai) · [Documentation](https://sureforgetech.com/docs/) · [Support](https://sureforgetech.com/support/)**

## The product family

| Product | Description | Status |
| --- | --- | --- |
| **[SureForge](https://sureforgetech.com/products/sureforge/)** | Local CLI for bounded AI-assisted development. Runs validation and independent review, then returns results to a person. It never merges code autonomously and needs no hosted service. | Developer preview · macOS and Linux |
| **[SureForge Studio](https://sureforgetech.com/products/studio/)** | Standalone workstation for coordinating coding-agent sessions across repositories, with context, execution history, audit trails, pause/resume, and handoff. | Early development |
| **[PolicyForge / SureForge Policy](https://sureforgetech.com/products/policyforge/)** | Proprietary cloud compliance automation that aggregates evidence from existing security tools and prepares control findings and assessment artifacts. | Proprietary |
| **[TrellisForge / SureForge Trellis](https://sureforgetech.com/products/trellisforge/)** | Jira Cloud app for editable work hierarchies, planning, saved views, and reporting; respects individual Jira permissions. | Product information in development |
| **[BugNarrator / SureForge Capture](https://sureforgetech.com/products/bugnarrator/)** | Local-first macOS narrated-testing app with searchable transcripts, screenshot timeline markers, and bug extraction. | Apache-2.0 · Free · macOS 14+ |
| **[Terminal Workspace / SureForge Terminal](https://sureforgetech.com/products/terminal-workspace/)** | Native macOS SSH and SFTP workspace with key and host trust management, snippets, and port forwarding. | Product information in development |
| **[SureForge FM — FileMaker Data API Tools](https://sureforgetech.com/products/sureforge-fm-data-api/)** | MIT-licensed VS Code extension for FileMaker Data API operations, schema, batch work, Layout Mode, and generated-app starters. | MIT · Free and open source |
| **[SureForge FM — Alfred Snippets](https://sureforgetech.com/products/sureforge-fm-alfred/)** | MIT-licensed Alfred snippets for FileMaker development on macOS. Requires Alfred Powerpack. | MIT · Free |
| **[FlowForge / SureForge Flow](https://sureforgetech.com/products/flowforge/)** | Multi-tenant application platform with control/runtime planes, tenant metadata, deployment management, and SSO support. Some capabilities remain in development. | In development |
