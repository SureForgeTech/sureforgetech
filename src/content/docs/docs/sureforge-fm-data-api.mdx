---
title: SureForge FM Data API
description: FileMaker Data API tools for Visual Studio Code.
---

SureForge FM Data API is a free and open-source VS Code extension for FileMaker developers. It supports create, read, update, and delete operations, query building, schema management, batch operations, Layout Mode design, connection profiles, and a Next.js starter for generated applications. It is MIT-licensed and is not affiliated with Claris or FileMaker.
