---
title: SureForge Policy
description: Security and compliance automation for cloud environments.
---

SureForge Policy is a proprietary security and compliance automation platform that aggregates evidence from security tools, evaluates controls, and prepares findings and assessment artifacts, including OSCAL 1.1.3 exports. It can import SureForge Agent run reports and delivery journals as evidence, recorded as operator diagnostics rather than signed attestations. Product documentation is in preparation.
