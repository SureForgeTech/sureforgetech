SureForge FM Snippets is a free collection of [Alfred](https://www.alfredapp.com/) snippets for Claris FileMaker developers on macOS. Instead of typing out a full function or remembering its parameters, you type a short trigger such as `;fmlet` and Alfred replaces it with the FileMaker syntax.

The collection has 360 snippets covering FileMaker calculation functions, multi-line `Let`, `Case` and `While` blocks, `ExecuteSQL`, JSON functions and `Get` functions. Snippets work in the FileMaker calculation dialog or in any code editor.

The source lives in the public GitHub repository [ABD-Enterprises/filemaker-alfred-snippets](https://github.com/ABD-Enterprises/filemaker-alfred-snippets). It is licensed under the MIT License.

## What you need

- A Mac running macOS.
- [Alfred](https://www.alfredapp.com/) installed.
- The **Alfred Powerpack**, purchased and activated. Snippets are a Powerpack feature.

## Install

<Steps>

1. Open the [filemaker-alfred-snippets repository](https://github.com/ABD-Enterprises/filemaker-alfred-snippets) on GitHub and download the `FileMaker_Functions.alfredsnippets` file from the root of the repository.
2. Double-click the downloaded file. Alfred asks you to import the snippet collection. Confirm the import.
3. Open **Alfred Preferences**, go to **Features** > **Snippets**, and make sure **Automatically expand snippets by keyword** is checked.
4. Test it: open a text editor or a FileMaker calculation dialog and type `;fmlet`. It should expand into a multi-line `Let` statement.

</Steps>

After import, the snippets appear in Alfred as a collection named **FileMaker Functions**. Each snippet is named after its function, for example **FM Let**.

## How triggers work

Every trigger starts with `;fm`, followed by the function name or an abbreviation, all in lowercase. The semicolon is rarely typed directly before letters in normal writing, so snippets are unlikely to expand by accident.

- **Most triggers** are `;fm` plus the function name in lowercase. For example, `;fmwordcount` inserts `WordCount (  )`.
- **`Get` functions** are `;fmget` plus the `Get` parameter in lowercase. For example, `;fmgetfoundcount` inserts `Get ( FoundCount )`.
- **Some functions** use a different trigger, such as `;fmsub` for `Substitute`, `;fmmid` for `Middle` and `;fmdatefn` for `Date`. Every one of these is listed in the reference tables below.

Many snippets insert the function name with empty parentheses, for example `JSONSetElement (  )`, so you can fill in the parameters yourself. Others insert named placeholders, such as `Left ( text ; numberOfCharacters )`, that you replace with your own values.

## Multi-line blocks

Three snippets insert a ready-made, indented block.

`;fmlet` inserts:

```
Let ( [
    var = value
] ;
    result
)
```

`;fmcase` inserts:

```
Case (
    test1 ; result1 ;
    test2 ; result2 ;
    defaultResult
)
```

`;fmwhile` inserts:

```
While ( [
    i = 0 ;
    result = ""
] ;
    i < count ;
    [
        i = i + 1 ;
        result = List ( result ; i )
    ] ;
    result
)
```

The tables below list every snippet that inserts placeholders or uses a different trigger. The rest of each category follows the standard pattern: `;fm` plus the function name in lowercase, inserting the function name with empty parentheses. The full list, with every trigger and expansion, is the file `data/FileMaker_Functions_Alfred_Snippets.csv` in the repository.

## Customize snippets

You can change any snippet after importing it:

<Steps>

1. Open **Alfred Preferences**.
2. Go to **Features** > **Snippets**.
3. Select the **FileMaker Functions** collection.
4. Double-click a snippet to edit its name, keyword (trigger) or snippet text.

</Steps>

## Get updates

The repository is where new and corrected snippets are published. To get the latest collection, download the current `FileMaker_Functions.alfredsnippets` file from the [repository](https://github.com/ABD-Enterprises/filemaker-alfred-snippets) and import it as described in [Install](#install). If you have edited snippets in Alfred, make a note of your changes first.

## Suggest a snippet

Contributions are welcome. All snippet data is kept in `data/FileMaker_Functions_Alfred_Snippets.csv`. To propose a new snippet or a change, fork the repository, edit the CSV file and open a pull request. You do not need to build the `.alfredsnippets` file yourself; the maintainers regenerate it after a change is merged.

New triggers must start with `;fm`, be all lowercase, stay short but descriptive, and not clash with an existing trigger. Snippet text should match the syntax in the official Claris documentation. See `docs/CONTRIBUTING.md` in the repository for the full guidelines.

## Troubleshooting

- **Nothing happens when I type a trigger.** Check that the Powerpack is active and that **Automatically expand snippets by keyword** is checked under **Features** > **Snippets** in Alfred Preferences.
- **The collection is missing.** Double-click `FileMaker_Functions.alfredsnippets` again and confirm the import.
- **A trigger does not exist.** Some functions use a shortened trigger, and JSON triggers use the full function name (for example `;fmjsonsetelement`). Check the tables above or the CSV file in the repository.
