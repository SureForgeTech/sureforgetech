---
title: SureForge FM Snippets
description: Alfred productivity snippets for FileMaker developers.
---

SureForge FM Snippets is a free set of Alfred productivity snippets for FileMaker developers on macOS, including triggers such as `;fmlet`, `;fmcase`, `;fmjsonset`, and `;fmsql`. It requires Alfred Powerpack, is MIT-licensed, and is not affiliated with Claris or FileMaker.
