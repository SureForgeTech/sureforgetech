---
title: BugNarrator / SureForge Capture
description: Narrated software testing for macOS.
---

BugNarrator is a local-first macOS menu bar app for narrated testing, with searchable transcripts, screenshot timeline markers, and bug extraction from a recording session. Optional local transcription and bring-your-own AI provider support are available features. The software is Apache-2.0 licensed and supports macOS 14 or newer.
